# 프롬프트 템플릿

## 기억 탐색

```text
[가족 에세이 기억 탐색]
- 붙잡을 순간 / 기억할 이야기 / 전할 마음:
- 가족 관계:
- 내가 확실히 기억하는 사실:
- 불확실한 부분:
- 주 가치:
- AI에게 원하는 질문·대안:
```

## 장 집필

```text
[짧은 장 집필]
- 장 번호와 목표 자수:
- 실제 장면·감각:
- 이 장에서 달라지는 이해:
- 받치는 주 가치:
- 사람이 직접 쓴 핵심 문장:
- 만들면 안 되는 사실:
```

## 비평과 재작성

```text
[비평 후 재작성]
- 현재 글자 수:
- 점검: 가족 중심성 / 주 가치 / 진정성 / 과장 / 출처 / 8000자
- 유지할 부분:
- 기각하거나 줄일 부분:
- 사람의 판단:
```

작업 후 프롬프트와 판단을 창작 로그에 옮긴다.
