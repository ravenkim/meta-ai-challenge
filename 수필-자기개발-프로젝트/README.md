# 가족 에세이 트랙

실제 경험·회고를 중심으로 한 **8,000자 이내 가족 에세이**를 만듭니다.

## 핵심 파일

- `canon/주제.md`: 붙잡을 순간, 가족 관계, 경험·재구성 경계
- `canon/가치-가이드.md`: 연결·발견·즐거움 중 주 가치
- `canon/핵심-논지.md`: 글이 끝내 말할 한 문장
- `canon/책임-규칙.md`: 개인정보·사실·출처·AI 진정성
- `story/목차-전체.md`: 2~4개 짧은 장과 자수 예산
- `state/창작-로그/_템플릿.md`: AI 활용과 반복 개선 기록
- `output/원고/`: 최종 원고

에세이는 실제 경험을 존중하되 기억의 한계를 밝힙니다. AI가 만들어낸 장면을 실제 기억처럼 쓰지 않습니다.
