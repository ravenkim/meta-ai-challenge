# 05 핵심 프롬프트 5개

`02-프롬프트-창작과정.md`의 12단계 중, 작품의 소재·인물·핵심 장치·본문·결말을 실제로 고정한 프롬프트만 골랐다. 제외한 단계는 구조 배분(플롯), 문장 다듬기(퇴고·교정), 분량·출처 확인, 액자 도입처럼 앞선 결정을 보강한 작업이다.

## 1. 시놉시스 발상

- 목적: 가족 주제의 단편 소재를 여러 방향으로 탐색한 뒤, 채택안을 고정
- 선정 이유: 「아버지의 받아쓰기」가 여기서 선택됐다.

```text
가족(Family)을 주제로 단편 시놉시스를 5개 제안해줘.
형식은 소설 트랙 기준이고, 본문 공백 포함 8,000자 이내에서 4~5개 씬으로 완결돼야 해.
각 시놉시스마다 중심 갈등이 무엇인지 한 줄로 적어줘.
이야기 시작 시점의 관계와 끝에서 달라지는 관계를 각각 한 문장씩 대비해서 적어줘.
Connection·Discovery·Entertainment 중 어느 가치와 가장 잘 맞는지도 표시해줘.
눈물 강요·죽음·화해 후 포옹·갑작스러운 병 같은 클리셰를 이 소재가 어떻게 피할 수 있는지 이유를 붙여줘.
실제 경험이 아니라 상상·허구 트랙이라는 전제이고, 실존 인물을 특정할 수 있는 설정은 넣지 마.
서로 겹치지 않는 방향이어야 하고, 짧은 분량에서 한 사건에 집중할 수 있는지도 함께 판단해줘.
```

## 2. 캐논·인물 설계

- 목적: 확정 시놉시스를 인물 캐논으로 고정하고, 상투형 인물에서 벗어나게 함
- 선정 이유: 정태석·정하윤·서미경의 관계와, 본문에서 대사로 설명하지 않는다는 규칙이 여기서 정해졌다.

```text
확정한 시놉시스 「아버지의 받아쓰기」를 바탕으로 등장인물 캐논 문서를 만들어줘.
각 인물마다 나이·직업·현재 생활 조건을 먼저 정리해줘.
다른 가족 구성원과의 현재 관계와 평소 대화 방식을 적어줘.
겉으로 드러내지 않는 숨겨진 욕구를 인물별로 하나씩 정해줘.
다른 인물에 대한 오해나 착각이 있다면 무엇인지 구체적으로 적어줘.
이 정보들은 본문에서 대사로 직접 설명되지 않고 행동·소품·장면으로만 드러나야 한다는 전제로 작성해줘.
"왜 이렇게 행동하는지"를 상황으로 짐작하게 만드는 디테일을 우선해줘.
```

## 3. 반복 오답 단어 재검토

- 목적: 결말의 감동 장치가 될 핵심 단어의 진부함 여부 점검
- 선정 이유: 「괜찮다」를 「같이」→「가치」(구개음화 오답)로 바꾼 결정이 결말 전체를 바꿨다.

```text
이 이야기에서 감동 포인트로 쓰려는 「괜찮다」에 특별한 의미가 있는지 점검해줘.
지금 설계에서 그 장치가 하는 역할을 근거와 함께 정리해줘.
한국 가족 소재 창작물에서 이미 많이 쓰여 진부하게 읽힐 위험이 있는지도 짚어줘.
위험이 있다면 어느 부분이 상투적으로 보이는지 먼저 알려줘.
같은 감정적 효과를 내면서도 덜 상투적인 대안을 3개 제시해줘.
각 대안이 인물의 나이·발음·직업·생활 조건과 맞는지, 결말의 동작과 설명 없이 연결되는지도 확인해줘.
기존 캐논의 다른 설정과 충돌하는 후보는 따로 표시해줘.
최종적으로 유지할지 교체할지 권고를 한 문장으로 정리해줘.
```

## 4. 초안 집필

- 목적: 확정된 캐논·인물·씬 기획을 문장으로 완성
- 선정 이유: 11세 1인칭, 감정 직접 서술 금지, 8,000자 제한이 본문 문장으로 처음 구현된 단계다.

```text
확정된 캐논·인물·씬 기획을 바탕으로 씬 1부터 씬 4까지 초고를 이어서 써줘.
각 씬은 `story/에피소드/`에 정리된 목표와 인물 정보를 따라줘.
화자는 정하윤, 만 11세의 1인칭이고, 전체 목표 글자 수는 공백 포함 8,000자 내외야.
감정을 직접 서술하는 문장("슬펐다", "행복했다") 대신 동작·사물·감각으로 상태를 보여주는 문장으로 써줘.
화자 나이가 실제로 쓸 법한 어휘와 문장 길이를 유지해줘.
전문 용어나 성인 수준의 통찰이 서술자 목소리로 들어가지 않게 해줘.
직전 씬에서 이어지는 인물의 심리·관계 상태를 자연스럽게 이어줘.
이 씬이 끝난 뒤 다음 씬으로 넘어갈 여지를 마지막 문단에 남겨줘.
인물을 딱하게 그리는 위로 대사, 주제를 대신 읽어 주는 문장은 넣지 마.
```

## 5. 결말 강화

- 목적: 아버지가 쓴 「가치」의 의미를 딸이 알아보는 순간을 결말에서 부각
- 선정 이유: 빨간 펜 동그라미로 주제를 설명하지 않고 닫는 결말 장치가 여기서 확정됐다.

```text
결말에서 「가치」를 보고 하윤이 아버지의 연결·관계를 알아채는 순간이 더 부각됐으면 해.
서술자가 감동이나 깨달음을 직접 정리하는 문장으로 끝내지 마.
그런 문장이 이미 있다면 정확히 어느 문장인지 인용해줘.
그 문장을 지웠을 때 앞선 장면만으로 같은 의미가 전달되는지 검토해줘.
전달이 안 된다면 어느 장면을 보강해야 하는지 제안해줘.
전달이 된다면 그 문장을 대체할 결말 동작을 제안해줘.
제안한 동작이 이야기 전체에서 반복돼 온 소재(빨간 펜, 동그라미, 반복 단어)와 연결되는지 확인해줘.
사전을 찾거나 뜻을 설명해 주는 장면처럼 주제를 대신 읽어 주는 안은 기각해줘.
```
