# 제출 전 체크리스트

제출 후 수정·재제출할 수 없으므로 전부 확인합니다.

## 작품

- [ ] 본문이 가족을 중심 주제로 다룬다.
- [ ] 사랑과 관계 / 추억 / 일상 / 성장 / 세대 간 소통 중 하나 이상이 장면에 있다.
- [ ] 연결 / 발견 / 즐거움 중 선택한 가치가 설명이 아니라 장면으로 드러난다.
- [ ] 본문이 공백 포함 8,000자 이내다.
- [ ] 제목·작가명·제출 기록을 제외한 본문만 세었다.
- [ ] 제출 파일이 최종 원고와 같다.

## AI 활용과 진정성

- [ ] 사용한 AI 도구와 핵심 프롬프트를 빠짐없이 적었다.
- [ ] 기각·수정·반복 개선 과정이 창작 로그와 일치한다.
- [ ] AI가 한 일과 직접 한 일을 과장 없이 구분했다.
- [ ] AI 활용 비율의 단계별 근거가 있다.

## 저작권·윤리

- [ ] 작품은 참가자 본인의 창작물이다.
- [ ] 외부 자료의 출처와 라이선스를 확인했다.
- [ ] 이용 권한이 불분명한 자료가 없다.
- [ ] 실존 가족의 이름·연락처·민감정보를 제거하거나 동의를 받았다.
- [ ] 실화와 허구의 경계를 거짓 없이 기록했다.
- [ ] 표절·허위 사실·AI 환각을 최종 점검했다.

## 공개 및 제출

- 작품 공개 선택: 공개 / 비공개
- [ ] 비공개 선택도 심사·수상 대상에서 제외되지 않음을 확인했다.
- [ ] 01·02·03의 내용이 서로 모순되지 않는다.
- [ ] 공식 사이트의 최신 형식별 제출 기준을 다시 확인했다.
