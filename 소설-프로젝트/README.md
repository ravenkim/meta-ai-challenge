# 가족 단편소설 트랙

상상·허구를 중심으로 한 **8,000자 이내 가족 단편소설**을 만듭니다.

## 핵심 파일

- `canon/주제/가족.md`: 붙잡을 순간, 가족 관계, 실화·허구 경계
- `canon/주제/가치-가이드.md`: 연결·발견·즐거움 중 주 가치
- `canon/책임-규칙.md`: 개인정보·출처·AI 진정성
- `state/인물/가족-관계.md`: 인물과 관계 변화
- `story/플롯/전체흐름.md`: 3~5개 씬과 목표 자수
- `state/창작-로그/_템플릿.md`: AI 활용과 반복 개선 기록
- `output/원고/`: 최종 원고

## 완료 조건

1. 가족이 배경이 아니라 갈등·변화의 중심이다.
2. 주 가치가 구호가 아니라 장면으로 드러난다.
3. 초안 → 판단 → 재작성 과정이 기록돼 있다.
4. 본문이 공백 포함 8,000자 이내다.
5. 루트 `submit/`의 01·02·03과 기록이 일치한다.
