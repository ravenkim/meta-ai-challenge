# 작성 규칙

## 원고 규칙

- 가족이 핵심 갈등과 변화의 중심이다.
- 주 가치 1개는 필수, 부 가치는 선택이다.
- 3~5개 씬, 목표 자수 합계는 8,000 이하로 설계한다.
- 완성 원고가 공백 포함 8,000자를 넘으면 `output/원고/`에 확정하지 않는다.
- 실화·허구 경계와 가족 개인정보 처리는 `canon/책임-규칙.md`를 따른다.

## 반복 개선 기록

작업마다 `state/창작-로그/`에 다음을 남긴다.

- 목표와 사용 AI 도구
- 핵심 프롬프트 원문
- AI 응답 요지
- 채택·기각·수정 이유
- 재프롬프트와 달라진 점
- 직접 수행한 부분과 당시 글자 수

## 커밋 타입

- `theme`: 가족 주제·가치·메시지
- `char`: 가족 인물·관계
- `plot`: 씬 구조
- `draft`: 초안
- `revise`: 퇴고
- `session`: 창작 로그
- `submit`: 제출 패키지

커밋을 만들 때만 다음 문맥을 포함한다.

```text
[AI-CONTEXT]
AI역할: ...
인간역할: ...
반복개선: ...
글자수: ... / 8000
[/AI-CONTEXT]
```
