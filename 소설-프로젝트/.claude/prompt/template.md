# 프롬프트 템플릿

## 기획

```text
[가족 단편 기획]
- 붙잡을 순간 / 기억할 이야기 / 전할 마음:
- 가족 관계:
- 실화·허구 경계:
- 주 가치(연결·발견·즐거움):
- 핵심 메시지:
- 원하는 대안 수:
- 인간이 이미 결정한 내용:
```

## 씬 집필

```text
[씬 집필]
- 씬 번호와 목표 자수:
- 시작·끝 상황:
- 관계의 변화:
- 이 씬이 보여 줄 주 가치:
- 반드시 유지할 인간 작성 문장:
- 피할 클리셰·과장:
```

## 비평과 재작성

```text
[비평 후 재작성]
- 현재 글자 수:
- 점검: 가족 중심성 / 가치의 장면화 / 인과 / 진부함 / 8000자
- 유지할 부분:
- 기각하거나 줄일 부분:
- 사람의 판단:
- 재작성 범위:
```

작업 후 프롬프트, 결과 요지, 채택·기각 이유를 창작 로그에 옮긴다.
